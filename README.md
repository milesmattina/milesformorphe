# Miles for Morphe

Independent Product Marketing Manager application for Morphe. A separate copy of the approved `milesmattina/miles-for-ritual` source at commit `958b4e8`.

## Development

- `npm ci`
- `npm run dev`
- `npm run lint`
- `npm run typecheck`
- `npm run build`

The approved introduction, eight-card deck, three case studies, media, links, and closing section are preserved. Only company, job-title, and resume-object references change. The supplied November resume replaces the downloadable PDF, rendered preview, and accessible text.

Morphe's official website informed the monochrome, muted metallic, and rose-powder visual system. Archivo Black and Inter are open-source substitutes for its Monument Extended and Beausite Classic typography.

The original lightweight CSS palette has a physical back hinge, double-sided metallic lid, mirror, recessed powder pans, and latch. Opening pivots the lid; closing reverses it. Animation state guards, completion fallback, keyboard activation, Escape, and reduced-motion support are included. The approved resume viewer keeps download, zoom/fit, full/half screen, minimize, restore, and close.

Portfolio assets are unchanged. Stills and posters are eager; videos defer downloading, autoplay muted and inline when visible, loop without controls, and pause offscreen. The removed website-build timelapse remains absent.

No existing project, deployment, credentials, or backend is shared or changed. No backend connection is needed by the approved site.
